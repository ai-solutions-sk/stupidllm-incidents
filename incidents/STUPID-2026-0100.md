On February 7, 2026, a user filed openai/codex issue #11006, titled "Codex
wiped the whole drive by accident. Oops!", after asking Codex to delete a
single old backup file and instead watching it run a command that wiped
the entire drive. The report includes a screenshot of Codex's reasoning
process and the command it executed, showing the disconnect between the
narrowly scoped request and the drive-level destructive action taken. The
user asked OpenAI to add a safety feature requiring a yes/no confirmation
before Codex runs a "critical command" capable of this kind of damage. The
issue was filed with the labels `CLI`, `enhancement`, and `sandbox`, and
was closed as not planned with no visible OpenAI staff response, fix, or
statement on whether the data was recoverable.
