A Cline Desktop App user (romemozu) reported that failed sessions were not actually stopping: of their 10 non-Anthropic sessions, 9 were marked `failed` in the local session store, and several continued making API calls for 20 to 23 hours after the point of failure. One session alone racked up 416 API calls and 112,057,985 input tokens — an average of about 183,696 input tokens per call, driven by Cline resending the full, growing conversation on every call. Totaled across all sessions: 1,156 calls, 212,352,674 input tokens, 834,634 output tokens, and 165,124,705 cache-read tokens. A second, separate defect compounded it: the reporter's Cline Credits balance had gone negative (-$0.26) even though the sessions in question used models explicitly labeled FREE, such as `cline-free/deepseek-v4.1-flash` and `cline-free/muse-spark-1.3-contributor`. Neither problem was new — the report links cline/cline#13367, describing the same runaway-after-failure behavior, and cline/cline#8074, describing the same FREE-model billing bug — meaning both defects had already been filed and remained unfixed at the time of this report. As of publication, #14256 had no visible maintainer response.
