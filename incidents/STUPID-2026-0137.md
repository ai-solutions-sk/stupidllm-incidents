A Gemini CLI user (rsanzi) reported on GitHub that the agent, while fixing a
coordinate-space mismatch bug in a Python clustering function, correctly
identified the problem and then fell into a closed loop: it repeated two
near-identical lines — acknowledging it was "stuck in a loop," promising to
re-read the file and construct the correct replace command, then simply
re-stating that promise — about a dozen times without ever applying the edit.
Gemini CLI's own bot-triage labeled it `kind/bug` and `priority/p1`, and other
maintainer/community accounts subsequently marked roughly a dozen separate
reports as duplicates of this same loop, meaning it was not an isolated
occurrence. The issue drew no maintainer comment addressing the underlying
cause and was closed as "not planned" on 2025-12-28 in a stale-issue sweep,
with a user reporting the same behavior still present three months later.
